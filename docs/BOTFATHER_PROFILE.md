این متن‌ها با نسخه فعلی ربات هم‌خوان هستند:
راه‌اندازی تعاملی، مدت چالش قابل‌تنظیم، تسک‌های شخصی، گزارش روزانه، داشبورد و یادآوری.

```text
🚀 ARIAMIR TRAKER

✅ چه تسک‌هایی برات مهمه؟

بعدش هر روز گزارش می‌گیری، پیشرفتت رو می‌بینی و با یادآوری، استریک و داشبورد روی مسیر می‌مونی.

✨ امکانات
• راه‌اندازی تعاملی (روز + تسک)
• تسک‌های پیشنهادی و سفارشی
• گزارش روزانه با دکمه‌های سریع
• ثبت حال و یادداشت
• داشبورد پیشرفت و درصد
• استریک و نشان‌ها
• تاریخچه گزارش‌ها
• یادآوری شخصی (به وقت تهران)
• پنل مدیریت برای ادمین

🧩 نمونه تسک‌های پیشنهادی
🧠 کنترل عادت
📚 درس / مطالعه
🧘 مدیتیشن
🏋️ ورزش
📵 مدیریت گوشی
💤 خواب منظم
💧 آب کافی
🗣️ زبان
💻 کدنویسی

شروع کن با /start
لازم نیست کامل باشی؛ فقط باید ادامه بدی.
```

## پست معرفی کامل‌تر

```text
اگر همیشه چالش شروع می‌کنی و وسطش رها می‌شه،
مشکل معمولاً «بی‌برنامگی گزارش» است نه بی‌ارادگی.

ARIAMIR TRAKER یک ربات تلگرامی ساده و جدی است:

1) اول مشخص می‌کنی چالش چند روزه باشد
2) تسک‌هایت را از پیشنهادها یا به‌صورت سفارشی می‌چینی
3) هر روز گزارش می‌دهی
4) پیشرفت، استریک و تاریخچه‌ات می‌ماند

مناسب برای:
• ساخت عادت
• مطالعه و ورزش
• نظم دیجیتال
• چالش‌های شخصی ۲۱ تا ۹۰ روزه (یا بیشتر)

شروع سریع:
👉 @ARIAMIRTRAKER_BOT
دستور: /start
```
