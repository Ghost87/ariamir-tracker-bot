## ۱) Oracle Cloud Always Free ⭐
**جذاب‌ترین رایگان واقعی**

- VM همیشه روشن
- Python کامل + systemd/docker
- ۲–۳ ربات سبک معمولاً جا می‌شود
- لینک: https://www.oracle.com/cloud/free/

**مزایا:** رایگان بلندمدت، کنترل کامل  
**معایب:** ثبت‌نام/کارت/ظرفیت منطقه گاهی اذیت می‌کند

---

## ۲) Koyeb Free ⭐
**جذاب برای deploy آسان از GitHub**

- instance رایگان، معمولاً بدون sleep کلاسیک Render
- اتصال به GitHub + env `BOT_TOKEN`
- لینک: https://www.koyeb.com/

**مزایا:** ساده، مناسب polling  
**معایب:** محدودیت منابع free؛ سیاست free ممکن است عوض شود

---

## ۳) Zeabur
- deploy ساده
- گاهی credit ماهانه
- لینک: https://zeabur.com/

خوب برای تست سریع ۲–۳ سرویس سبک.

---

## ۴) Pella (مخصوص ربات تلگرام)
- تمرکز روی hosting بات
- Python/Node
- لینک: https://www.pella.app/telegram-bot-hosting

قبل از اتکا، محدودیت free و region را چک کن.

---

## ۵) GitHub Actions هوشمندتر (بدون اکانت دوم)
به‌جای اکانت جعلی:

### A) ریپو را Public کن
- دقایق private تمام‌شده را دور می‌زند (معمولاً)
- secretها همچنان Secret بمانند (توکن در کد نباشد)

### B) چند پنجره کوتاه به‌جای ۴×۳.۵ ساعت
مثلاً فقط ساعات اوج:
- ۲۰:۰۰–۲۳:۰۰ تهران

### C) حافظه روی `bot-data` (از قبل پیاده شده)

**واقعیت:** هیچ‌وقت ۲۴/۷ کامل مثل VPS نمی‌شود.

---

## ۶) Render / Railway / Fly
| سرویس | نکته ۲۰۲۶ |
|---|---|
| Render Free | بعد از بیکاری sleep → برای polling بد |
| Railway | بیشتر تریال/اعتبار؛ همیشه رایگان پایدار حساب نکن |
| Fly.io | قابل تنظیم؛ free پیچیده/محدود شده |

اگر از Render استفاده می‌کنی، یا **Background Worker پولی** لازم است یا معماری webhook + بیدار نگه داشتن.

---

## ۷) PythonAnywhere
- مخصوص Python
- free برای always-on polling محدودیت دارد
- بیشتر برای تست/وب‌اپ

---

## ۸) چابکان / هاست ابری ایرانی ربات
- پشتیبانی Python دارند (برخلاف بعضی هاست‌های «ربات PHP»)
- لینک نمونه: https://chabokan.net/products/cloud-hosting/telegram-bot/
- قیمت را با نیاز ۳ کاربر بسنج؛ از VPS نیم‌میلیونی منطقی‌تر است اگر پلن کوچک داشته باشند

---

## ۹) PC خانه + ضدقطع
- `python bot.py` روی سیستم همیشه روشن
- یا Raspberry Pi
- رایگان، ولی وابسته به برق/اینترنت خانگی

---

## ۱۰) تبدیل به Webhook (راه فنی جذاب)
اگر حاضر به تغییر کوچک کد باشی:
- به‌جای polling دائمی → webhook
- روی سرویس‌های serverless/scale-to-zero ارزان‌تر می‌شود
- نیاز: URL عمومی HTTPS

برای الان ضروری نیست؛ وقتی هاست always-on پیدا کردی polling ساده‌تر است.

## پیشنهاد مسیر برای تو (۳ کاربر، بودجه کم)

### مسیر طلایی
1. **Koyeb Free** یا **Oracle Free** را امتحان کن  
2. اگر یکی‌شان راه افتاد همان را نگه دار  
3. GitHub Actions را فقط بکاپ/شبانه نگه دار  

### مسیر اگر فقط ایرانی/ساده می‌خواهی
- هاست/پلتفرم ابری با **پشتیبانی رسمی Python always-on** (مثل چابکان) با ارزان‌ترین پلن  
- یا VPS خیلی کوچک (زیر ۲۰۰ اگر پیدا شد) — نه ۵۰۰

### این‌ها را نکن
- اکانت GitHub دوم برای دور زدن محدودیت  
- Cloudflare Workers بدون بازنویسی  
- VPS/هاست نیم‌میلیون برای ۳ نفر

## چک‌لیست قبل از خرید هر سرویسی
1. Python 3.10+ دارد؟  
2. پروسه ۲۴/۷ می‌ماند یا sleep می‌کند؟  
3. `pip install` آزاد است؟  
4. دیسک ماندگار برای SQLite دارد؟  
5. به `api.telegram.org` دسترسی دارد؟  
6. ۲–۳ پروسه همزمان اجازه می‌دهد؟
