# توضیح کوتاه برای رزومه / نمونه‌کار

## نسخه یک‌خطی (انگلیسی)

Built **ARIAMIR TRAKER** (`@ARIAMIRTRAKER_BOT`), a Telegram personal-growth challenge bot with interactive onboarding, customizable duration/tasks, daily reporting, streak analytics, SQLite persistence, admin tools, Docker packaging, and GitHub Actions scheduled execution with durable state.

## نسخه ۲–۳ خطی (فارسی)

ربات تلگرامی **ARIAMIR TRAKER** را طراحی و پیاده‌سازی کردم: سیستم مدیریت چالش رشد شخصی با راه‌اندازی تعاملی (انتخاب مدت چالش و تسک‌ها)، گزارش روزانه دکمه‌ای، داشبورد پیشرفت/استریک، پنل ادمین، دیتابیس SQLite پایدار، یادآوری زمان‌بندی‌شده، و اجرای خودکار روی GitHub Actions همراه با ذخیره‌سازی حافظه بین اجراها.

## Bulletهای رزومه

- طراحی و توسعه ربات تلگرام برای مدیریت چالش‌های رشد شخصی با onboarding تعاملی و تسک‌های قابل‌پیکربندی
- پیاده‌سازی لایه داده SQLite (WAL)، آمار/استریک، بکاپ، پنل مدیریت و خروجی CSV
- آماده‌سازی Docker/systemd و workflowهای GitHub Actions برای اجرای زمان‌بندی‌شده با persistence

## کلمات کلیدی فنی

Python · python-telegram-bot · SQLite · Docker · GitHub Actions · systemd · dotenv · Inline Keyboards · Job Queue
